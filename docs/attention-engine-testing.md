# בדיקת מנוע זיהוי המבט עם מצלמה אמיתית

המנוע מעריך **לאן מופנה המבט ביחס למסך**. הוא לא מודד ריכוז. הבדיקה כאן
בודקת דבר אחד: האם המנוע מזהה נכון מבט למסך, מבט החוצה, היעדר פנים ומצבים
לא ודאיים.

## הפעלה

```powershell
cd frontend
npm run dev
```

פותחים ב-Chrome או ב-Edge את אחת הכתובות:

- `http://localhost:3000/__experiments/attention-engine`: בלי התחברות ובלי שרת.
- `http://localhost:3000/learning?engine=new`: בתוך עמוד הלמידה (צריך להתחבר). הבחירה נשמרת בדפדפן. כדי לחזור לניסוי הישן: `?engine=legacy`.

> אם קונטיינר Docker ישן תופס את פורט 3000, מריצים `npm run dev -- --port 3001`.

## הכנה

1. תאורה מלפנים או מהצד, לא חלון מאחור.
2. מרחק רגיל מהמסך (50–70 ס״מ). הפנים צריכות למלא לפחות כחמישית מרוחב התמונה.
3. לוחצים **"הפעלת מצלמה"** ומאשרים גישה. בפינת הווידאו אמור להופיע קצב של כ-10–15 פריימים לשנייה.

## בדיקה 1: בלי כיול

| פעולה | תוצאה צפויה |
|---|---|
| מביטים במסך | "לא ניתן לקבוע בוודאות", עם הסבר שצריך כיול |
| מסובבים את הראש הצידה בחדות | "מבט מחוץ למסך" |
| יוצאים מהתמונה | "לא זוהו פנים" אחרי כשנייה |

## בדיקה 2: כיול

1. לוחצים **"כיול אישי"**. הדף עובר למסך מלא ומופיעות 9 נקודות, אחת אחרי השנייה.
2. מביטים בכל נקודה עד שהיא מתמלאת. מותר להזיז ראש ועיניים באופן טבעי, אבל לא להזיז את הכיסא.
3. בסיום מוצגת **איכות הכיול**: מצוין, טוב, בינוני או חלש. מצוין או טוב זה מצב תקין. אם יוצא חלש, חוזרים על הכיול.

## בדיקה 3: מצבים אחרי הכיול

מבצעים כל שורה לכ-5 שניות ובודקים את "מצב נוכחי" ואת ציר הזמן.

| # | פעולה | תוצאה צפויה |
|---|---|---|
| 1 | מביטים במרכז המסך | מבט לכיוון המסך |
| 2 | מביטים בכל אחת מ-4 הפינות | מבט לכיוון המסך (בפינות ייתכן גם "לא ודאי") |
| 3 | מביטים רק בעיניים מעבר לשולי המסך, בלי להזיז את הראש | מבט מחוץ למסך, או "לא ודאי" בגבול |
| 4 | מסובבים את הראש לחלון או לקיר | מבט מחוץ למסך |
| 5 | מביטים במקלדת או בטלפון | מבט מחוץ למסך |
| 6 | מכסים את המצלמה או יוצאים מהתמונה | לא זוהו פנים |
| 7 | מצמוצים רגילים בזמן מבט למסך | המצב **לא** משתנה |
| 8 | עוצמים עיניים ל-3 שניות | "עצימת עיניים ממושכת" ברשימת הסימנים האפשריים |
| 9 | מתקרבים מאוד למסך או זזים הצידה בכחצי מטר | "לא ודאי" עם המלצה לכיול מחדש |
| 10 | מרכיבים או מורידים משקפיים | בודקים את איכות מדידת העיניים. אם היא יורדת, המנוע עובר ל"ראש בלבד" |

## מה לרשום

לכל שורה רושמים מה הוצג, כמה זמן עבר עד השינוי, ואם הייתה קפיצה בין
מצבים. כדאי לרשום גם: איכות הכיול, הטעות הצפויה, מצלמה (מובנית או חיצונית
ומיקומה), תאורה ומשקפיים.

עם הנתונים האלה מכווננים את `FUSION_DEFAULTS` ב-`fusion.js` ואת
`TEMPORAL_DEFAULTS` ב-`temporal.js`.

## פרטיות

הווידאו, נקודות הפנים ונתוני הכיול מעובדים בדפדפן בלבד, ושום דבר מהם לא
נשמר ולא נשלח. הכיול נמחק בטעינה מחדש של הדף.
