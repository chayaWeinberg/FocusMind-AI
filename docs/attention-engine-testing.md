# בדיקת זיהוי כיוון המבט עם מצלמה אמיתית

המנוע מעריך **לאן מופנה המבט ביחס למסך**. הוא לא מודד ריכוז. הבדיקה כאן
בודקת דבר אחד: האם המנוע מזהה נכון מבט למסך, מבט החוצה, היעדר פנים ומצבים
לא ודאיים. **אין צורך בכיול.**

## הפעלה

```powershell
# שרת (בטרמינל אחד)
cd backend
.venv\Scripts\activate
uvicorn app.main:app --reload

# אתר (בטרמינל שני)
cd frontend
npm run dev
```

פותחים ב-Chrome או ב-Edge את `http://localhost:3000`, נכנסים לחשבון ועוברים
ל**"למידה חכמה"** (`/learning`).

> אם קונטיינר Docker ישן תופס את פורט 3000, מריצים `npm run dev -- --port 3002`
> ופותחים את `http://localhost:3002`.

## הכנה

1. תאורה מלפנים או מהצד, לא חלון מאחור.
2. מרחק רגיל מהמסך (50–70 ס״מ). הפנים צריכות להיות במרכז התמונה.
3. לוחצים **"הפעלת מצלמה"** ומאשרים גישה בדפדפן.
4. **מביטים במסך כרגיל כ-3 שניות.** בזמן הזה מוצג פס "התאמה", והמנוע לומד
   את מיקום הישיבה שלכם.

## בדיקה: מצבים

מבצעים כל שורה לכ-5 שניות ובודקים את המצב שמוצג בכרטיס "כיוון המבט".

| # | פעולה | תוצאה צפויה |
|---|---|---|
| 1 | מביטים במרכז המסך | מבט לכיוון המסך |
| 2 | מביטים בפינות המסך | מבט לכיוון המסך (בפינות ייתכן גם "לא ניתן לקבוע בוודאות") |
| 3 | מסובבים את הראש לחלון או לקיר | מבט מחוץ למסך |
| 4 | מביטים במקלדת או בטלפון | מבט מחוץ למסך |
| 5 | מכסים את המצלמה או יוצאים מהתמונה | לא זוהו פנים (אחרי כשנייה) |
| 6 | מצמוצים רגילים בזמן מבט למסך | המצב **לא** משתנה |
| 7 | עוצמים עיניים ל-3 שניות | "סימן אפשרי לעייפות: עצימת עיניים ממושכת" |
| 8 | מזיזים את הכיסא (קדימה, אחורה או הצידה) ונשארים כך | אחרי כ-2 שניות מופיע שוב פס "התאמה", ואז המצב חוזר לתקין |
| 9 | לוחצים "התאמה מחדש למיקום שלי" ומביטים במסך | פס "התאמה" ואחריו מבט לכיוון המסך |
| 10 | עוברים ללשונית אחרת וחוזרים | בזמן שהלשונית מוסתרת המעקב מושהה, ואחר כך ממשיך |

## בדיקה: הערכת ריכוז

ההערכה מופיעה בכרטיס "כיוון המבט" אחרי כ-8 שניות של מבט מול המצלמה.

| # | פעולה | תוצאה צפויה |
|---|---|---|
| 1 | מביטים במסך כחצי דקה | ריכוז גבוה (75% ומעלה) |
| 2 | מביטים הצידה כ-10 שניות | ההערכה יורדת מתחת ל-50% ("ריכוז נמוך"), עם הסבר "המבט היה הרבה מחוץ למסך" |
| 3 | חוזרים למסך | ההערכה עולה בהדרגה בתוך כ-20–30 שניות |
| 4 | עוצמים עיניים ל-3 שניות | ההערכה יורדת ל-25% לכל היותר, עם "העיניים עצומות כרגע". אחר כך מופיעה "עצימות עיניים ממושכות" למשך 2 דקות |
| 5 | מפהקים (פה פתוח לרווחה כשנייה וחצי) | "פיהוקים" עולה ל-1 וההערכה יורדת בכ-12% למשך 5 דקות |
| 6 | מביטים במקלדת בלי לעצום עיניים | "מבט מחוץ למסך", אבל **לא** "עיניים עצומות" |

ב**"פרטי המדידה"** (לחיצה פותחת) מוצגות סטיית המבט האופקית והאנכית במעלות
והגבול שלהן. כשמבט למסך מסומן כ"מחוץ למסך" (או להפך), רושמים את הסטייה
שמוצגת. כך אפשר לכוונן את הגבולות.

## בדיקה: סטטיסטיקה של המפגש

1. בוחרים סרטון ומפעילים אותו.
2. במהלך הניגון מביטים במסך, מסתכלים הצידה כמה פעמים ויוצאים מהתמונה.
3. בכרטיס **Focus Monitor** בודקים שהזמנים מתחלקים בין המצבים, ש"יציאות מהמסך" עולה, ושציר הזמן מתמלא (משבצת לכל 5 שניות).
4. עוצרים את הסרטון: הסטטיסטיקה מפסיקה להצטבר.
5. מכבים את המצלמה בזמן ניגון: הזמן נספר כ"לא נמדד (מצלמה כבויה)".

## מה לרשום

לכל שורה רושמים מה הוצג, כמה זמן עבר עד השינוי, ואם הייתה קפיצה בין
מצבים. כדאי לרשום גם: מצלמה (מובנית או חיצונית ומיקומה), תאורה ומשקפיים.

עם הנתונים האלה מכווננים את `GAZE_MODEL` ב-`signals.js`, את `BASELINE_DEFAULTS`
ב-`baseline.js`, את `FUSION_DEFAULTS` ב-`fusion.js` ואת `CONCENTRATION_DEFAULTS`
ב-`concentration.js`.

## פרטיות

הווידאו ונקודות הפנים מעובדים בדפדפן בלבד, ושום דבר מהם לא נשמר ולא נשלח.
ההתאמה למיקום נמחקת בטעינה מחדש של הדף.
