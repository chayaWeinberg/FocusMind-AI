# Deferred work

These issues are known and were left out of the stabilization pass on purpose.
None of them blocks local development or the new attention engine.

## Security (before any public deployment)

- **Login/registration rate limiting**: there is no brute-force protection yet.
  Add per-IP and per-email throttling.
- **Session lifetime**: the JWT lasts 30 minutes (`ACCESS_TOKEN_TTL_MINUTES`)
  and is never refreshed. The UI notices the expiry only on the next page load
  or API call. Decide on a sliding session or refresh tokens once real API
  calls are made during study sessions.
- **CSRF**: the protection today is `SameSite=Lax` plus JSON-only endpoints,
  which is enough for a same-site setup. Add a CSRF token if the frontend and
  API are ever served from different sites.
- **MongoDB user**: the app connects with the root user created by Docker.
  Create a least-privilege user for the app database.

## Deployment

- There is no production setup yet. The frontend image runs the Vite dev
  server, and there is no reverse proxy. A production build needs a server
  that serves `dist/` and forwards `/api` to the backend, with HTTPS and
  `ENV=production` (Secure cookies, no `/docs`).
- The frontend image copies `certs/` into `/app`. Make it a multi-stage build
  before publishing images.

## Code health

- `features/learning/useFaceLandmarker.js` (~700 lines) runs every experiment
  in one detection loop. The new engine will replace it (see
  `features/attention-engine/README.md`). It is kept unchanged until then.
- The fixed-threshold estimators (`screenAttentionEstimator.js`,
  `screenAttentionTracker.js`) are superseded by the personalized classifier.
  Keep them as a baseline, then retire them.
- CSS: `SmartLearningPage.css` (~1900 lines) overlaps with
  `SignatureTheme.css`. Consolidate only together with a design review, so
  Design 15 does not change.
- `.gitignore` has duplicated sections (cosmetic).
- The MediaPipe WASM files in `frontend/public/mediapipe/wasm/` are both
  committed and regenerated by `scripts/copy-mediapipe-assets.mjs`. Consider
  ignoring them like the WebGazer assets.
- `.kiro/specs/` describe the original registration feature and are out of
  date.
- Starlette's `TestClient` shows a deprecation warning (anyio). It goes away
  with a FastAPI/Starlette upgrade.
