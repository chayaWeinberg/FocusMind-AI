# Bundled lesson videos (original FocusMind content)

The production image copies this folder and installs it on startup
(`SEED_CATALOG=true`, `DEMO_VIDEOS_DIR`), so a fresh deployment needs no Windows
machine, browser or local volume. Everything here was created for this project;
no third-party content is included.

- **FocusMind Academy:** 15 full lessons, about 3 minutes each, in 5 courses (Python,
  JavaScript, SQL, algorithms, Docker).
  - Each lesson teaches real concepts with explanation captions, code and output,
    step-by-step traces and a "check yourself" question. They have no narration.
  - Source: `frontend/scripts/academy-videos/lessons.mjs`.
  - Recorded with `node scripts/academy-videos/generate.mjs` (in `frontend/`), which
    writes here directly.
  - Manifest entries: `"kind": "academy"`.
- **Demonstration videos:** 16 short videos, about 90 seconds each, labelled "סרטון הדגמה",
  for the 3 demonstration courses.
  - Generated by `frontend/scripts/demo-videos/generate.mjs`, then copied here.

**Installation** is idempotent, by key and sha256. It never replaces videos that people
uploaded or chose, or videos a content manager removed.
